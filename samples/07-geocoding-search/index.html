Add your key
Search and geocoding need an ArcGIS Location Platform API key with the geocoding (not stored), geocoding (stored) and basemaps privileges. Copy .env.example to .env.local, paste your key after VITE_ARCGIS_TOKEN=, then restart npm run dev.
