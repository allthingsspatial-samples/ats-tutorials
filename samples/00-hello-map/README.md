# 00 Hello Map

The smallest ArcGIS Maps SDK for JavaScript app: a `Map` with the keyless `topo-vector` basemap in a `MapView`. It needs no API key and no account.

- SDK: `@arcgis/core` 5.1.27 (pinned)
- Build tool: Vite

```bash
npm ci
npm run dev
```

It is also the sample that proves the repo CI works.
